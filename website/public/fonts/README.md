`isocast-sans.woff2` is a subset of Mona Sans (variable, from github/mona-sans v2.0.27):
Latin characters only, the width (100–112.5), weight (400–650) and optical-size (11–32)
ranges this site uses, and the kerning, ligature, case and tabular/proportional-figure
features. Mona Sans is licensed under the SIL Open Font License 1.1
(`LICENSE-mona-sans.txt`); because a subset is a Modified Version and "Mona" is a
Reserved Font Name, the subset's internal name is "Isocast Sans".
