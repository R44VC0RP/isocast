Isocast 0.0.10 for Apple-silicon Macs (macOS 14+) and, for the first time, Linux (Ubuntu 24.04 and Debian 12, x86-64 and arm64). If you're on 0.0.9, Isocast › Check for Updates… installs it. Your permissions carry over. Windows comes in the next release.

**Isocast on Linux (new)**
- **Install:** download the `.deb` for your distro and `SHA256SUMS` from the release, check it and run `sudo apt install ./isocast-…deb`. There are packages for Ubuntu 24.04 and for Debian 12 (which needs PipeWire from bookworm-backports), and an Ubuntu 24.04 tarball with a per-user `install.sh`.
- **First launch offers to download Cisco's OpenH264** for H.264 encoding and live previews. It downloads and checks the codec as your user, never as root, and you can skip it and run `isocast-openh264-install` later. OpenH264 Video Codec provided by Cisco Systems, Inc.
- **Previews through shared memory:** an app on the same computer as its engine reads the monitors straight from shared memory, so the engine no longer encodes video for its own previews.
- **Virtual camera through v4l2loopback:** Start Virtual Camera feeds the program to a v4l2loopback device, the one labelled "Isocast Camera" if you have several. Isocast never loads the module or asks for root; if there's no device, it shows the one command that makes one.
- **Browser sources:** web pages render in a separate `isocast-browser` helper (WebKitGTK 6), with their sound, and restart on their own if a page crashes or hangs. They're in the Ubuntu 24.04 package; Debian 12's GTK is too old for them.
- **Looks at home:** the window's title bar is dark like the rest of the app, and shortcuts use Linux key names (Ctrl, Alt, Super) instead of Mac symbols.
- **Cameras:** NV12-only cameras (such as the FaceTime camera on Asahi Linux) are listed and record, a camera's infrared sensor no longer shows up as a second camera, and a USB webcam recorded with its own microphone starts cleanly instead of dropping off the bus. Camera access is reported as allowed or denied, with the fix.
- **`isocast doctor` checks real-time scheduling** for both the PipeWire server and Isocast's own audio capture, and says what to change when either runs without it.
- Thanks to **Mateusz Tymek** for NV12 cameras, cameras that start cleanly, camera access, OBS import from `~/.config/obs-studio`, flips, the Removed toast and source-removal fixes, and a CI fix ([#165](https://github.com/R44VC0RP/isocast/pull/165), [#167](https://github.com/R44VC0RP/isocast/pull/167), [#168](https://github.com/R44VC0RP/isocast/pull/168), [#169](https://github.com/R44VC0RP/isocast/pull/169), [#175](https://github.com/R44VC0RP/isocast/pull/175), [#181](https://github.com/R44VC0RP/isocast/pull/181), [#184](https://github.com/R44VC0RP/isocast/pull/184), [#199](https://github.com/R44VC0RP/isocast/pull/199)).

**On Mac**
- **Previews give way to the program:** while you record, stream or keep a replay buffer and the program keeps missing frames, previews step down to 15 fps, then 5 fps, then pause, and come back once it keeps up again.
- **Flip Horizontal and Flip Vertical** in a source's Transform menu. ISO files keep the picture as captured, and OBS scenes with a one-way flip import with it.
- **Web page sound is captured on the page's own audio thread,** so it keeps up when the page is busy. If a page's sound still has a gap, the recording counts it as an audio dropout instead of closing it up silently.
- Web pages can no longer end a recording by sending malformed sound.
- The **Removed** toast with Undo appears only once the change is applied, so it never offers to undo a removal that didn't happen.
- **Better bug reports:** Help › Report a Bug… sends a report even when the engine can't start, and the GitHub form it opens is filled in from your reviewed description.

**Known limits**
- Linux has no automatic updates: to update, finish any recording, quit Isocast, run `isocast engine shutdown` and install the newer `.deb` the same way.
- Debian 12 needs PipeWire 1.0.5 or later from bookworm-backports for screen and audio capture.
- Window sources aren't on Linux yet; capture a screen instead.
- Windows comes in 0.0.11, once its installer is code-signed.
