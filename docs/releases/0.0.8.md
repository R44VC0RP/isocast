Isocast 0.0.8 for Apple-silicon Macs (macOS 14+). If you're on 0.0.7, Isocast › Check for Updates… installs it. Your permissions carry over.

**A canvas for every destination**
- **Up to eight extra canvases,** each with its own size, frame rate, scenes or per-scene layouts, recording and stream destinations: 16:9 to Twitch and 9:16 to YouTube Shorts at the same time. The vertical canvas is now one of them, and existing setups load unchanged.
- **Per-destination settings:** each destination can set its own bitrate, rate control, keyframe interval and audio bitrate; destinations with the same format share one encoder.
- **In the app:** the canvas monitor next to the stage shows any canvas, with a menu of every canvas and its actions. The layout editor edits any canvas, and projectors, multiview, the replay buffer and the virtual camera work per canvas.
- OBS import brings in Aitum Multistream and Vertical Canvas setups (stream keys are never read), and obs-websocket answers the Vertical Canvas plugin's requests.

**Advanced masks**
- **Shape masks** (rectangle with rounded corners, circle, ellipse, polygon, star, heart) with soft edges, drawn with handles on the picture; **gradient masks**; and **source masks**, which use any source or scene, a video included, as a live mask, in step with the program frame by frame.
- Masks stack (intersect, add, subtract), every setting can be animated, and Advanced Masks filters come in through OBS import.

**Isocast tunes itself to your Mac**
- **A measured machine profile** drives the capacity warnings and Optimize, including ProRes and mixed H.264/HEVC setups.
- **A live quality governor** watches the encoders, GPU and memory while you record or stream, and steps down streams, previews, multiview and extra canvases when the Mac falls behind, then back up when it recovers. It never lowers your program or ISO files on its own, and settings you pin stay put. Settings › Advanced › Automatic Quality.
- **Safer defaults on base and 8 GB Macs.**

**Recordings you can trust more**
- **A frame budget across every output:** the program and ISO files always get frames first; previews, extra canvases, multiview, masks and the virtual camera give way before a recording could drop a frame.
- **Videos and stingers no longer repeat a frame** now and then at 60 fps, and looping playlists don't stutter between files.
- **Clear recording targets:** choose next to Record whether a recording starts a new project or adds a take to the current timeline.
- HE-AAC audio in MKV files plays on time; switching to a scene collection with a source named "edited" renames it instead of refusing; system audio always leaves out Isocast's own sounds.
- Optimize says so when it can't measure this Mac instead of reporting nothing to change.

**Behind the scenes:** every recording, ISO file, canvas, mask, transition and editor export, including Final Cut, Premiere and Resolve projects, is now checked frame by frame against an independent model before each change ships.
