Isocast 0.0.7 for Apple-silicon Macs (macOS 14+). If you're on 0.0.6, Isocast › Check for Updates… installs it. Your permissions carry over.

**Take your edit to Final Cut Pro, Premiere Pro or Resolve**
- **Export for your editor:** File › Export › For Final Cut Pro / Premiere Pro / DaVinci Resolve writes a project that opens with every angle on its own track, lined up and cut like your Isocast edit. It points at your original files, so nothing is re-encoded or copied. Crops, markers and each source's audio come along. From the command line: `isocast timeline export --nle fcpxml|xmeml|otio`.
- **Sound in the editor:** playback now has sound, in sync with the picture (2× and 4× are pitch-corrected). It stays silent while you're recording or streaming system audio, so it never ends up in a take.
- **Export › With Vertical (9:16)** in the editor, and 10-bit angles in 8-bit programs export cleanly.

**Faster and steadier**
- **One GPU device for the whole app,** and frames Isocast can't keep up with no longer cost a GPU conversion.
- **A much lighter multiview:** about half the GPU time and memory with projectors open.
- Isocast recovers from a stalled or lost GPU without restarting.

**Vertical canvas**
- Each canvas fails on its own: a problem on one never stops the other's streams.
- **Replay buffer** and **virtual camera** for the vertical canvas.
- A scene without its own vertical layout now shows the main picture fitted and centred (nested scenes and animations included). Scenes without a vertical layout record differently on the vertical canvas than in 0.0.6.

**Polish and safety**
- Every screen was checked at every window size; clipped labels, overlapping text and cut-off controls are fixed, and narrow windows use short labels with full names in tooltips.
- Plugins can't widen their own access through folders they name, hotkeys or obs-websocket.
- Project files are saved when you quit; obs-websocket can open projectors; HE-AAC audio in MKV files plays on time.
- This update window now shows the full release notes.
