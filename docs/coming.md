# Coming

These are being built and are not in a release yet. Each will be on the
API, the CLI and MCP, as well as in the app.

## Hotkeys

Every action bindable to a key: scenes, Record, Stream, markers, splits
and more. Stored per profile, and global (working while the app isn't
focused) where macOS allows.

## Virtual camera

The program as a macOS camera, so Zoom, Meet, FaceTime and other apps can
use it. Start and stop it from the app, the CLI or an agent.

## Also planned

- A replay buffer: keep the last seconds in memory and save them on
  command.
- Projectors and a multiview grid.
- Timelines in the app (a clip bar), on top of the
  [timelines](timelines.md) the engine has today.
- WGSL shader filters and WebAssembly sources for [plugins](plugins.md).
- Later: a second (vertical) canvas, SRT and WHIP streaming, NDI, Syphon,
  Audio Unit plugins, Windows.
